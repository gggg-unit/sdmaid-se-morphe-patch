# gggg-unit SD Maid SE FOSS Patches

Independent GPLv3 patch bundle compatible with Morphe. Not affiliated with or
endorsed by SD Maid SE, d4rken, Morphe, Doom, or Paresh.

**[➕ Add to Morphe](https://morphe.software/add-source?github=gggg-unit/sdmaid-se-morphe-patch&name=gggg-unit%20SD%20Maid%20SE%20FOSS%20Patches)**
· [Download .mpp](https://github.com/gggg-unit/sdmaid-se-morphe-patch/releases/latest)

## Use

1. Open **Add to Morphe** on Android and confirm adding the source.
2. Select an original **[GitHub FOSS APK](https://github.com/d4rken-org/sdmaid-se/releases)**.
3. Apply **Unlock Pro (FOSS)**.

**Google Play APKs are unsupported**, even though the package name is the same.
There is no version-number lock; newer FOSS releases work only while the target
code structure remains compatible. GitHub Actions checks the latest release daily.

## If patching fails

Check the APK source and update Morphe and this patch source. If it still fails,
[report the full patching log](https://github.com/gggg-unit/sdmaid-se-morphe-patch/issues/new?template=patch-failure.yml)
with the APK version, download source, and Morphe version. A generic
“fails to patch” message is insufficient to identify the cause.
